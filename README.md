# YOLO Dataset Viewer

Настольный просмотрщик изображений и YOLO-разметки для проверки датасетов компьютерного зрения. Отображает bounding boxes и контуры сегментации поверх изображения. Модель нейросети, CUDA и подключение к интернету для просмотра не нужны.

## Возможности

- Выбор локального каталога с подпапками `images` и `labels`.
- Просмотр JPEG, PNG и BMP, включая расширения в верхнем регистре.
- Переход к следующему и предыдущему изображению с циклической навигацией.
- Масштабирование под окно с сохранением пропорций и без увеличения маленьких изображений.
- Прямоугольники и полигоны с контурами и полупрозрачной заливкой.
- Отображение номера изображения и количества корректно прочитанных фигур.
- Пропуск некорректных строк, бесконечных/NaN-координат, отрицательных классов и недопустимых размеров рамок.

Программа открывает файлы для чтения: изображения и разметка на диске не изменяются. Это инструмент просмотра, а не редактор аннотаций.

## Запуск готового EXE

Скачайте `YoloDatasetViewer-Windows-x64.zip` или отдельный `YoloDatasetViewer.exe` из [Releases](https://github.com/Himera2134567/yolo-dataset-viewer/releases). Распакуйте ZIP и запустите EXE. Python и виртуальное окружение на целевом компьютере не требуются. Сборка предназначена для Windows 10/11 x64 и не подписана цифровой подписью.

Нажмите **Выбрать датасет** и укажите каталог такого вида:

```text
selected-folder/
  images/
    sample.jpg
  labels/
    sample.txt
```

Имена изображения и TXT должны совпадать без расширения. Для датасета с `train/images` выбирайте папку `train`, для `valid/images` — папку `valid`. Изображение без соответствующего TXT показывается без наложений. Подпапки внутри `images` рекурсивно не обходятся.

## Форматы разметки

```text
# Bounding box: class center_x center_y width height
0 0.5 0.5 0.4 0.2

# Polygon: class x1 y1 x2 y2 x3 y3 ...
1 0.1 0.1 0.9 0.1 0.5 0.9
```

Координаты нормированные, от 0 до 1; класс — целое неотрицательное число. Для полигона нужны минимум три пары координат. Края рамок ограничиваются границами изображения. Строки-комментарии в примере приведены для пояснения и пропускаются парсером.

## Структура

| Файл | Назначение |
| --- | --- |
| `dataset_viewer.py` | Интерфейс Tkinter, загрузка каталога, парсер YOLO, рисование фигур, масштабирование и навигация. |
| `smoke_checks.py` | Проверки парсера и отрисовки; создание временного синтетического датасета для проверки интерфейса. |
| `tests/test_core.py` | Запуск проверок через `unittest`. |
| `requirements.txt` | Pillow для чтения, масштабирования и наложения фигур. |
| `build.py`, `requirements-build.txt` | Сборка одного EXE через PyInstaller. |

## Исходники и сборка

Для воспроизведения выпуска используйте Python 3.12.10+ из ветки 3.12, x64, с Tkinter. Выпуск собирается на Python 3.12.14, Pillow 12.0.0 и PyInstaller 6.21.0.

```powershell
python -m pip install -r requirements-build.txt
python -m unittest discover -s tests
python dataset_viewer.py
python build.py
```

Сборка появляется в `dist/YoloDatasetViewer.exe`. Она включает Python, Tk/Tcl и Pillow. Контрольные суммы файлов опубликованы в `SHA256SUMS.txt` в релизе.

## Проверки и ограничения

```powershell
.\YoloDatasetViewer.exe --self-test --self-test-report .\self-test.json
```

Проверки используют только синтетические данные: рамки и полигоны, некорректные строки, обрезку краёв рамок, масштабирование, наложение фигур, навигацию и неизменность исходных файлов. Реальные изображения пользователя в релиз не входят.

Имена классов из `data.yaml` не читаются; цвета служат для визуального различения фигур, а не для обозначения фиксированной таблицы классов. Программа не оценивает смысловую точность разметки, самопересечения полигонов или качество модели. Очень большие изображения требуют памяти на полное декодирование. Работу на всех версиях Windows и форматах изображений отдельно не проверяли.
